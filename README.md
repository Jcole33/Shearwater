# Shearwater VR Pilot Interface (archived)

Senior design project, Santa Clara University, 2020–2021. Funded by the
U.S. Navy in cooperation with MBARI.

A Unity (C#) application that gives a drone pilot a 360° view through an
Oculus Rift headset. It displays live video from a Ricoh Theta V camera,
a heads-up display driven by MAVLink telemetry from Mission Planner, AR
markers for mission waypoints, and a minimap.

The interface was validated end to end against Mission Planner's simulator.

This repository is archived and kept for reference alongside the thesis.

**Thesis:** [Project Shearwater Ground Effect UAV](https://scholarcommons.scu.edu/idp_senior/77)
(Clark, Cole, Karat, Nickels, Wolfe, 2021)

My contribution: the VR pilot interface in `Assets/MyScripts`.
